# C 语言练习区

编译器用你已装的 **Visual Studio 2026 自带的 MSVC（14.51）**，工程文件已经建好，
不用装 MinGW，也不用配环境变量。

## 用法一：Visual Studio（你在用的这个）

**双击 `c-practice.sln`** 打开工程，然后：

- `F5` —— 编译并以调试模式运行（能下断点）
- `Ctrl+F5` —— 编译并直接运行（不调试，跑完不立刻退窗口）

**代码写在 `指针验证.c` 里**，或者右键左侧「源文件 → 添加 → 新建项」加新文件。

> ⚠️ **一个工程只能有一个 `main()`**。如果你加了第二个带 `main` 的 `.c` 文件，
> 编译会报 `LNK2005 / LNK1168` 之类的链接错误。解决办法二选一：
> ① 都写在同一个文件里；② 右键那个暂时不用的文件 → 属性 → 「从生成中排除」→ 选「是」。

**调试指针特别有用的两个操作**（`F5` 跑起来之后）：

- 在行号左边点一下 = 下断点；鼠标悬停在变量上就能看值
- 「调试 → 窗口 → 内存 → 内存 1」，地址栏输入变量名，能直接看到那块内存的字节

## 用法二：VS Code（更轻，看单个文件快）

用 VS Code 打开这个文件夹 → 打开 `.c` 文件 → `Ctrl+Shift+B` 选「编译并运行」。
（C/C++ 扩展已装，重开 VS Code 后就有补全和 `F5` 调试。）

## 用法三：不想开编辑器

双击 `编译并运行.cmd`（默认编译运行 `指针验证.c`，也可以把别的 `.c` 拖到它上面）。

## 三种方式的编译参数是一样的

```
/std:c11  /W4  /utf-8
```

- `/std:c11`：按 C11 标准编译，`for (int i = 0; ...)` 这种写法才合法
- `/W4`：四级警告。新手最该看的就是警告，它经常提前告诉你哪里要出事
- `/utf-8`：源码按 UTF-8 读，中文注释和中文输出不会乱码

## VS 常见操作小抄（忘了就看这张表）

左侧那个面板叫「解决方案资源管理器」，**默认是收起来的**，要点小三角一层层展开：

```
解决方案 'c-practice'
└ c-practice                ← 点它左边的小三角 ▸ 展开
   ├ 引用
   ├ 外部依赖项
   └ 源文件                  ← 再点它左边的小三角 ▸ 展开
      ├ 指针验证.c           ← 双击这个，代码才会出现在中间
      └ 指针练习1.c          ← 自己练手用；写进 main 后会报 LNK2005，按下面那张表处理
```

如果哪天「源文件」这一层不见了：**直接右键 `c-practice` 项目名也一样能加文件**，
不用非得先找到「源文件」。

| 想干什么 | 怎么做 |
| --- | --- |
| 打开/切换代码文件 | 双击资源管理器里的 `.c` 文件 |
| 编译并运行（看结果） | `Ctrl+F5`（窗口会停住，按任意键才关） |
| 调试（下断点、看内存） | `F5`（程序跑完窗口会立刻关，所以看结果用 Ctrl+F5） |
| 新建练习文件 | **右键 `c-practice`（不用先找「源文件」）** → 添加 → 新建项 → 选「C++ 文件(.cpp)」→ 文件名改成 `xxx.c` → 添加 |
| 加完文件报 LNK2005 / LNK1168 | 两个文件都有 `main`。右键不用的那个 → 属性 → 「从生成中排除」→ 选「是」 |
| 更快的临时办法 | 在旧的 `main` 前面加 `#if 0`、后面加 `#endif`，把它关掉 |
| 右侧面板不见了 | `Ctrl+Alt+L` |
| 想让 F5 跑完也停住 | 在 `return 0;` 前加一行 `getchar();` |
