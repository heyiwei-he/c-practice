# C 语言练习区

这个文件夹已经配好编译器（用你装的 Visual Studio 2026 自带的 MSVC），
不用再装 MinGW，也不用配环境变量。

## 用法一：VS Code（推荐）

1. VS Code 里「文件 → 打开文件夹」，选这个 `c-practice` 文件夹
2. 打开任意一个 `.c` 文件
3. 按 `Ctrl+Shift+B` → 选「编译」，终端里会显示编译结果
   - 想编译后直接看输出：`Ctrl+Shift+B` → 选「编译并运行」
4. 想要代码补全、跳转、F5 断点调试：装一个扩展
   - 扩展面板（`Ctrl+Shift+X`）搜 `C/C++`，装微软那个（ms-vscode.cpptools）
   - 装完按 `F5` 就能单步调试了

## 用法二：不想开编辑器

把 `.c` 文件放在这个文件夹里，**双击「编译并运行.cmd」**即可
（默认编译运行 `指针验证.c`；也可以把别的 `.c` 文件拖到它上面）。

## 编译参数说明

```
cl /nologo /std:c11 /W4 /utf-8
```

- `/std:c11`：按 C11 标准编译，允许 `for (int i = 0; ...)` 这种写法
- `/W4`：开到四级警告。新手最该看的就是警告，它经常提前告诉你哪里要出事
- `/utf-8`：源码按 UTF-8 读，中文注释和中文输出才不会乱码
