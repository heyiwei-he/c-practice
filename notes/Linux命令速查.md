# 后端开发够用的 Linux 命令速查

> 只收「后端/服务器开发真的会用到」的，不追求全。每条后面写清"什么时候用"。
> 打印一页纸贴墙上就够。

## 一、文件与目录（每天都会用）

| 命令 | 什么时候用 |
| --- | --- |
| `pwd` | 先看清自己在哪个目录（迷路时第一个敲的） |
| `ls -lh` | 列文件，带大小和人类可读单位 |
| `cd 目录` / `cd ..` / `cd ~` | 进目录 / 上一层 / 回家目录 |
| `mkdir -p a/b/c` | 一次建多层目录，已存在也不报错 |
| `cp -r 源 目标` | 复制（`-r` 用于目录） |
| `mv 源 目标` | 移动，或改名 |
| `rm 文件`、`rm -rf 目录` | 删除。**`-rf` 没有回收站，敲之前先 `pwd` 确认位置** |
| `cat 文件` / `less 文件` | 看文件内容（大文件用 `less`，`q` 退出） |
| `tail -f 日志` | 实时看日志增长——排查服务问题的第一命令 |
| `find . -name "*.c"` | 按名字找文件 |

## 二、权限与用户

| 命令 | 什么时候用 |
| --- | --- |
| `ls -l` | 看权限（`-rwxr-xr-x` 那段） |
| `chmod +x 脚本.sh` | 让脚本可执行（"Permission denied" 时） |
| `chmod 644 文件` / `755 目录` | 设常用权限（文件 644、目录 755） |
| `sudo 命令` | 需要管理员权限时；**每次 sudo 前想一下这条命令在干什么** |
| `whoami` | 看当前用户（很多时候问题是"你以为你是 root"） |

## 三、进程与服务

| 命令 | 什么时候用 |
| --- | --- |
| `ps aux \| grep java` | 看某个程序在不在跑 |
| `top` 或 `htop` | 看谁在吃 CPU / 内存（`q` 退出） |
| `kill -9 PID` | 进程卡死杀不掉时（先试 `kill PID`） |
| `nohup java -jar app.jar &` | 让程序在后台跑，关掉终端也不停 |
| `Ctrl+C` / `Ctrl+Z` + `bg` | 中断 / 挂起当前程序 |

## 四、网络（后端必用）

| 命令 | 什么时候用 |
| --- | --- |
| `ping 主机` | 先确认网络通不通 |
| `curl http://localhost:8080/api` | 调接口、看返回——比装 Postman 还快 |
| `curl -X POST -d '{"a":1}' -H "Content-Type: application/json" URL` | 测 POST 接口 |
| `ss -lntp` | 看哪些端口在监听、被谁占着（"端口被占用"时用） |
| `ip addr` | 看本机 IP（连不上数据库/服务时先看这个） |
| `ssh 用户@主机` | 连服务器 |
| `scp 文件 用户@主机:/路径` | 传文件上去 |

## 五、包管理与磁盘

| 命令 | 什么时候用 |
| --- | --- |
| `sudo apt update` | 装东西前先更新索引（不更新会装到老版本） |
| `sudo apt install 名字` | 装软件（如 `build-essential`、`cmake`、`openjdk-17-jdk`） |
| `dpkg -l \| grep 名字` | 查装没装 |
| `df -h` | 磁盘满了吗（"No space left" 时） |
| `du -sh *` | 哪个目录最占空间 |
| `tar -xzf 包.tar.gz` | 解压 |

## 六、管道与文本处理（Linux 的精髓）

| 命令 | 什么时候用 |
| --- | --- |
| `命令 \| grep 关键字` | 从输出里筛行（配合 `ps`、`dpkg -l`、日志） |
| `grep -rn "关键字" .` | 在代码目录里搜内容（找"这个函数谁在用"） |
| `grep -v 关键字` | 排除某些行 |
| `wc -l` | 数行数（日志有多少条、代码多少行） |
| `sort \| uniq -c \| sort -rn` | 统计出现次数并排序（分析访问日志的经典组合） |
| `> 文件` / `>> 文件` | 覆盖写 / 追加写 |

## 七个最容易踩的坑

1. **`rm -rf` 没有回收站**：敲之前先 `pwd` 和 `ls`，确认路径。
2. **`sudo` 不是万能钥匙**：`sudo rm` 更容易把系统搞坏。
3. **`~` 是家目录，`/` 是根目录**：`cd /` 不是回家。
4. **路径区分大小写**：`File.c` 和 `file.c` 是两个文件。
5. **`cd` 只影响当前终端**：开新窗口还是老位置。
6. **`apt update` 和 `apt upgrade` 不一样**：前者只更新索引。
7. **命令找不到（command not found）**：先 `echo $PATH`，再考虑是不是没装。
